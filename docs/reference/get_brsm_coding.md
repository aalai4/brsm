# Extract Stored brsm Coding Metadata

Retrieves coding metadata from a `brsm_coded_data` object or a
`brsm_fit` object created from coded data.

## Usage

``` r
get_brsm_coding(object)
```

## Arguments

- object:

  A `brsm_coded_data` data frame or `brsm_fit` object.

## Value

A coding list with `method` and `factors` entries.
